# IronLog — the workout diary

**Version 1.0 (in development)** · React Native · Expo SDK 57 · TypeScript · Supabase · Expo SQLite

IronLog's V1 has one purpose: **be the best possible digital workout diary** — plan, log, save, review, edit and track every workout, offline-first. Intelligent Training (recommendations, plateau detection, AI) is deliberately **Version 2** and is not part of this codebase. V1 collects clean, structured data so V2 can build on it.

> **Build status:** see [docs/VERSION_1_SCOPE.md](docs/VERSION_1_SCOPE.md) for an honest done / not-done checklist. The foundation (data model, offline database, sync engine, calculations, auth, onboarding, home, profile/settings) is complete and tested; the workout screens (active workout, diary, routines, progress) are the next milestone.

## Stack

Expo Router · Zustand · TanStack Query · Zod + React Hook Form · Expo SQLite (local-first store) · Supabase Auth/Postgres/RLS · Expo SecureStore (session) · expo-notifications & expo-haptics (rest timer alerts).

## Installation

```bash
npm install          # .npmrc sets legacy-peer-deps for Expo's peer ranges
cp .env.example .env # then fill in your Supabase values
```

## Supabase setup (external step — needs you)

1. Create a project at <https://supabase.com>.
2. **Project Settings → API**: copy the *Project URL* and the **anon public** key into `.env` as `EXPO_PUBLIC_SUPABASE_URL` / `EXPO_PUBLIC_SUPABASE_ANON_KEY`. Never put the `service_role` key in the app.
3. Apply the schema: in the SQL editor run `supabase/migrations/0001_init.sql`, then `0002_seed_system_exercises.sql` (or `supabase db push` with the CLI). 0002 is generated by `npm run seed:sql`.
4. **Authentication → URL Configuration**: add the redirect `ironlog://reset-password` (password reset deep link).
5. (Optional for development) Authentication → Providers → Email → disable "Confirm email".

Without `.env` the app runs in **local-only mode** (sign-in screen offers a local mode; no cloud sync).

## Folder architecture

```
app/                 Expo Router routes ((auth), (tabs), onboarding, ...)
src/
  calculations/      pure, tested logic: units, volume, 1RM, PRs, stats, cloning, prefill
  database/          SQLite schema, migrations, repositories/, seed/ (203 exercises)
  sync/              local-first sync engine + scheduler
  stores/            Zustand: auth, profile, active workout session, rest timer, sync
  services/          bootstrap, haptics, notifications, stats aggregation, workout flows
  components/        design-system primitives and shared cards
  theme/  validation/  supabase/  hooks/  lib/  types/  utils/
supabase/migrations/ PostgreSQL schema + RLS + seed
tests/  docs/  scripts/
```
